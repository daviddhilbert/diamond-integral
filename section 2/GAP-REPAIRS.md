## Remark 2.47 (failure of curve selection in `Γ_∞`): repaired

`GammaCurveSelectionFailure.lean`:
- `remark_2_47`: for a definable curve `t ↦ (f t, h t)` on `D ⊆ Γ` with
  values in `Γ × (0, ∞)`, there are `N` and `ε > 0` with `h t ≥ ε` whenever
  `f t > N`. Proof from the cited piecewise rational-affine input (the one
  used for 2.41): on laws of slope `0` the second coordinate is one of
  finitely many constants; where it is below a fixed bound on laws of
  nonzero slope, the parameter is bounded (`gamma_power_law_source_bounded`),
  and on a bounded parameter range the first coordinate is bounded
  (`gamma_finite_power_laws_bounded`).
- `remark_2_47_no_approach`: the points of such a curve do not accumulate at
  `(∞, 0)`, so no curve approaches it.
- `remark_2_47_diagonal`: the diagonal approaches `(0, 0)` and `(∞, ∞)`.
Axioms: propext, Classical.choice, Quot.sound.

## Γ is stably embedded (November 17)

`GammaCodeSubstructure.lean`, `GammaCodeShift.lean`, `GammaTupleAutomorphisms.lean`,
`GammaStableEmbedding.lean` (namespace `DiamondIntegral.Section2.GammaStable`).
- `gamma_stably_embedded`: a subset of `Γ^k` whose RV-code preimage is
  definable over a small set `P` is a finite Boolean combination of
  half-spaces `{z : ∏ zᵢ^{mᵢ} ≤ δ}` with constants `δ` among the values of the
  substructure generated by `P` (`HalfspaceBoolean`). So `Γ` is stably
  embedded, with the induced structure of a divisible ordered abelian group.
- One-code step (`exists_automorphism_code`): over a small substructure `K`,
  codes `T, T'` whose values have the same ℤ-type over the values of `K` are
  conjugate over `K`. When `vrv T` is ℤ-independent, `VF(K) ∪ {c·T^m}` is a
  substructure (`codeSubstructure`; the junk conventions of the RV language
  give closure under the residue operations), the shift `c·T^m ↦ c·T'^m` is an
  isomorphism (`codeShiftEquiv`), quantifier elimination gives equal types
  (`code_sameUnaryType`), and strong homogeneity gives the automorphism.
- Tuple step (`exists_automorphism_code_tuple`): induction, enlarging `K` by
  the code substructure of each target code.
- Compactness through `Saturated.definable_finite_subcover_tuple`.
Axioms: propext, Classical.choice, Quot.sound.

## Lemma 2.12 over Γ-named bases: repaired (November 17)

`FiniteSetsGammaNames.lean`:
- `finite_named_real_definable`: a finite VF set definable over a real base
  `S` with Γ names is definable over `S`. Its coordinates are algebraic over
  `S` (`algebraic_vf_iff_real`), so it lies in a finite `S`-definable `Z`;
  automorphisms over `S` fix the values of `acl(S)` (`aut_fixes_acl_values`,
  a strictly monotone self-map of a finite linear order is the identity);
  the tuple step moves image codes back to codes of the same names while
  fixing `Z`, so the set is invariant; a finite invariant subset of `Z` is
  `S`-definable (`finite_invariant_definable`).
- `lemma_2_12_gammaNames`: the real 2.12 then applies; image and graph are
  definable over the base with the names.
- `normalize_eq`: on a canonical structure the normalized structure is the
  structure itself, so Γ-named relations are ordinarily definable.
Axioms: propext, Classical.choice, Quot.sound.
